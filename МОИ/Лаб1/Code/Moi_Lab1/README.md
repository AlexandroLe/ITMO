# ЛР 1. Вычисление яркости в точках на поверхности

Проект для лабораторной работы по курсу "Методы обработки изображений".
Программа считает RGB-яркость в заданных точках плоскости треугольника с учетом:

- перевода локальных координат точки в глобальные;
- нормали треугольника, ориентированной на наблюдателя;
- нескольких точечных направленных источников света;
- диаграммы излучения `cos(theta)`;
- освещенности `E = I * cos(alpha) / R^2`;
- BRDF `K * (kd + ks * (h dot N)^ke)`;
- итоговой яркости `L = 1/pi * sum(E * BRDF)`.

## Структура

```text
src/image_lab1/
  vector.py     базовая 3D-математика и RGB-операции
  models.py     Triangle, Light, Material, Scene и результаты
  lighting.py   основные формулы лабораторной
  io.py         чтение JSON и экспорт JSON/CSV
  render.py     простой PPM-рендер поверхности
  cli.py        запуск из консоли
examples/
  demo_scenario.json
tests/
  test_lighting.py
```

## Запуск

Из корня проекта:

```powershell
python -m image_lab1.cli --scenario ../examples/demo_scenario.json --out exports --render --scheme
```

Будут созданы:

- `exports/results.json` - подробные результаты по каждой точке и каждому источнику;
- `exports/results.csv` - таблица яркостей;
- `exports/triangle_render.ppm` - простая визуализация треугольника.
- `exports/scene_scheme.svg` - трехмерная схема сцены с треугольником, источниками, наблюдателем и точками расчета.

SVG-файл открывается в браузере. PPM-файл можно открыть многими просмотрщиками изображений или конвертировать в PNG.

## Входной JSON

Пример лежит в `examples/demo_scenario.json`. Локальная точка задается смещениями `x` и `y`
вдоль нормированных ребер `P0P1` и `P0P2`, как в ТЗ:

```json
{
  "points": [
    { "name": "center", "x": 1.8, "y": 1.2 }
  ]
}
```

Ось источника `axis` должна быть направлена туда, куда светит источник.
