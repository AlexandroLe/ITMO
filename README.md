## 📖 О репозитории

Данный репозиторий представляет собой структурированную учебную и инженерную базу знаний, содержащую выполненные лабораторные работы, практические задания, курсовые проекты, расчетные модели и отчёты по дисциплинам программной инженерии, вычислительных систем, сетевых технологий, низкоуровневого программирования и фундаментальной математики.

### 🌟 Ключевые особенности
* 🏛 **30+ дисциплин** — от базовых алгоритмов и дискретной математики до высокопроизводительных микросервисов и нейросетевых вычислений.
* 📦 **Полный цикл разработки** — спецификации, исходный код, юнит- и нагрузочные тесты, docker-контейнеризация и защищенные отчёты (PDF/DOCX).
* 🛠 **Разнообразие стека** — Java (Spring Boot), Python, C/C++, RISC-V & BComp Assembly, SQL, Jupyter, Mathcad, GPSS World, STM32 HAL.

## 📁 Структура репозитория

```text
ITMO/
├── ACC/            # Huawei HCIA-Datacom (eNSP топологии, отчеты)
├── AK/             # Архитектура компьютера (RISC-V Assembler, laba.s)
├── IOT/            # Проект "Тестер реакции" на Arduino (.ino)
├── OPI/            # Основы программной инженерии
├── АКГ/            # Алгоритмы компьютерной графики (Python, фильтры)
├── Алгоритмы/      # Алгоритмы и структуры данных (Задачи A-P)
├── АПС/            # Архитектура программных систем
├── БД/             # Базы данных (SQL, ER-диаграммы, PostgreSQL)
├── БЖД/            # Безопасность жизнедеятельности
├── ВС/             # Высокопроизводительные системы (Spring Boot REST API)
├── Дискретка/      # Дискретная математика (ДЗ 1-6, курсовая)
├── КИК/            # Коммуникации и командообразование
├── КомпСети/       # Компьютерные сети (Wireshark .pcapng, отчеты)
├── Матстат/        # Теория вероятностей и математическая статистика
├── Метопты/        # Методы оптимизации (Python, Симплекс-метод)
├── Метрология/     # Метрология, стандартизация и сертификация
├── Моделирование/  # Моделирование (GPSS World .gps)
├── МОИ/            # Методы обработки изображений (Python CLI render)
├── ОПД/            # Основы профессиональной деятельности (BComp)
├── ОСИ/            # Операционные системы (Linux C)
├── ПВС/            # Проектирование выч. систем (STM32, ARM Cortex)
├── РСХД/           # Распределенные системы хранения данных
├── САПР/           # САПР микросхем (Python net-var)
├── Схемотехника/   # Функциональная схемотехника (Logisim)
├── ТКС/            # Телекоммуникационные системы
├── ТН/             # Теория надежности (Mathcad .xmcd)
├── ТНВ/            # Технологии нейросетевых вычислений (Jupyter .ipynb)
├── ТПО/            # Тестирование ПО (JUnit 5, Selenium, JMeter)
├── Физика/         # Основы физических процессов (Python)
└── Электротехника/ # Основы электротехники (ТОЭ)
```
