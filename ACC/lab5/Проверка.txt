1. Проверка регистрации точек на контроллере: 
AC: 
display ap all 
Обе точки в статусе nor и получили IP 192.168.100.X, на схеме появились круги покрытия

2. Подключение STA1 к Wi-Fi: 
STA1: 
Вкладка Vap Map -> нажать Refresh -> выбрать HCIA-WLAN -> Connect 
Пароль: HCIA-Datacom 
Выбрать DHCP -> нажать Apply 
Статус стал Connected

3. Проверка параметров и связи на STA1: 
STA1 (вкладка Command): 
ipconfig 
Выдан IP 192.168.101.253, 
Gateway 192.168.101.254

ping 10.0.1.1 
Идет успешный пинг до S1 (0% потерь)

4. Подключение STA2 к Wi-Fi: 
STA2: 
Вкладка Vap Map -> выбрать HCIA-WLAN -> Connect 
Пароль: HCIA-Datacom 
Выбрать DHCP -> нажать Apply 
Статус стал Connected

5. Проверка параметров и связи на STA2: 
STA2 (вкладка Command): 
ipconfig 
Выдан следующий IP (192.168.101.252)

ping 10.0.1.1 
Идет успешный пинг до S1

ping 192.168.101.253 
Идет успешный пинг с STA2 на STA1

6. Финальная проверка клиентов на контроллере: 
AC: 
display station all 
Показывает Total: 2, обе станции активны в сети HCIA-WLAN
